# VoiceBridge

Программа для Windows, которая берёт звук из Discord и отдаёт его в виртуальный микрофон, чтобы друзей из Discord было слышно, когда вы разговариваете в Nektome.

## Зачем это нужно

Сразу уточним: прога не для того, чтобы общаться в Discord. В Discord и так всё работает, там есть свой микрофон. VoiceBridge сделан ровно для другой задачи: вы разговариваете в Nektome, а кенты пишут вам в Discord, и их голоса нужно туда же протащить.

Обычно это делается кучей костылей: вывесить звук на отдельный драйвер, лезть в настройки, слушать самому и показывать другим по очереди. Здесь всё проще: выбрали устройство вывода, выбрали микрофон, нажали «Старт». Дальше программа работает сама и тихо стоит в фоне.

Что происходит под капотом: голоса кентов из Discord играют у вас в наушниках, программа ловит этот звук и кладёт его в виртуальный кабель. Вы в Nektome выбираете кабель как микрофон, и собеседники в Nektome слышат ваших друзей из Discord, будто все сидят за одним столом. Никаких петель и шумов: сработает защита, если звук попытается вернуться сам в себя.

Что умеет:

- Захват системного звука через WASAPI shared mode, без лишних драйверов
- Отдача звука в виртуальный кабель, который подхватывает Nektome и любой другой чат
- Список программ: видно, что именно сейчас пищит в наушниках, и можно поймать звук только Discord, не цепляя игру и видео
- Живые индикаторы уровня на входе и на выходе, сразу видно, что сигнал идёт
- Отдельная громкость для системы и для микрофона, чтобы ничего не перекашивало
- Защита от петли: если звук пошёл из ваших же наушников обратно в захват, программа глушит канал и пишет об этом, вместо противного воет
- Автозапуск вместе с Windows и сворачивание в трей
- Проверка обновлений с GitHub Releases, без ручных скачиваний

## Зависимости

Без виртуального кабеля программа не работает: некуда складывать звук. Установщик сам проверяет, стоит ли VB-Cable, и если его нет, предлагает поставить прямо по ходу установки. Если отказались, программа предупредит об этом при первом запуске.

## Как установить и настроить

Скачайте `VoiceBridge-Setup-1.0.0.exe` из раздела [Releases](https://github.com/zxchm0nya/VoiceBridge/releases), запустите, пройдите мастер (папка, ярлыки, кнопка «Установить»). Если виртуального кабеля нет, установщик предложит поставить и его. В конце поставьте галочку «Запустить VoiceBridge».

Дальше по шагам:

1. В блоке «Маршрут» выберите свой наушники в поле «Система (вывод звука)».
2. В поле «Приёмник (микрофон)» выберите `CABLE Input (VB-Audio Virtual Cable)`.
3. Нажмите «Старт». Зелёный кружок и «Активно» внизу означают, что звук идёт.
4. В Nektome (или в любом другом чате): настройки звука → вход → устройство ввода → `CABLE Output (VB-Audio Virtual Cable)`.
5. Держите Discord открытым и включённым, его звук идёт в ваши наушники, дальше захват сделает всё сам.

Про эхо: оно появляется, если голосовой чат воспроизводит ваш голос в те же наушники, из которых идёт захват. Либо включите режим «Только при нажатии», либо поставьте отдельный выход для голосового чата. С разбором эхо помогает блок «Если слышите себя» в разделе «Помощь».

Если виртуального микрофона ещё нет, поставьте VB-Cable (в настройках программы это называется «Виртуальный кабель»), после чего перезайдите в «Маршрут» и выберите устройство заново.

## Сборка из исходников

```bash
git clone https://github.com/zxchm0nya/VoiceBridge.git
cd VoiceBridge

# Сборка приложения
dotnet build VoiceBridge.sln -c Release

# Или полный релиз (app + installer)
powershell -ExecutionPolicy Bypass -File build.ps1
```

После второго варианта готовый установщик лежит в `dist/VoiceBridge-Setup-1.0.0.exe`.

## Структура

- `VoiceBridge`: основное приложение (WPF, .NET 8, NAudio)
- `VoiceBridge.Installer`: установщик с проверкой и удалением
- `build.ps1`: чистка, сборка, упаковка setup
- `screenshots`: картинки для README
