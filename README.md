# VoiceBridge
VoiceBridge — бесплатная программа для Windows: передаёт звук из наушников в виртуальный микрофон VB-Cable, чтобы Discord и голосовые чаты слышали аудио из игр, видео и приложений. Выбирай отдельные приложения для захвата, следи за уровнем сигнала и обновляйся в один клик. Простой тёмный интерфейс и низкая нагрузка: выбери устройства и жми «Старт».
