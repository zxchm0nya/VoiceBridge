# VoiceBridge

Программа для Windows, которая пускает звук из ваших наушников прямо в виртуальный микрофон, чтобы Discord и любые голосовые чаты слышали то, что играет у вас в системе.

## Зачем это нужно

Допустим, вы играете и хотите показать друзьям звук из игры, видео или любого приложения. Обычно приходится лезть в настройки, включать захват, дергаться. Здесь всё проще: выбрали устройство вывода, выбрали микрофон, нажали «Старт». Дальше программа работает сама и тихо стоит в фоне.

По сути прога и сделана, чтобы просто общаться вместе. Вы сидите в Discord с кентами, кто-то включает мем, у кого-то игра звучит громко, вы сами смотрите видео, и всё это должно долететь до собеседников нормально, а не через шумный микрофон ноутбука. Выводите нужный звук в виртуальный микрофон, Discord его подхватывает, и дальше все слышат друг друга и всё, что происходит, как будто сидят за одним столом.

Что умеет:

- Захват системного звука через WASAPI shared mode, без лишних драйверов
- Отдача звука в виртуальный микрофон VB-Cable, его Discord и увидит
- Список программ: видно, что именно сейчас пищит в наушниках, и можно поймать звук только нужного приложения
- Голоса кентов тоже можно подхватить: в списке приложений есть и Discord, поймали его, и звук разговора ушёл в виртуальный микрофон. Это удобно, когда общаетесь сразу в двух местах, например в Discord и в игровом чате, и хотите, чтобы кенты прозвучали везде
- Живые индикаторы уровня на входе и на выходе, сразу видно, что сигнал идёт
- Отдельная громкость для системы и для микрофона, чтобы ничего не перекашивало
- Защита от петли: если звук пошёл из ваших же наушников обратно в захват, программа глушит канал и пишет об этом, вместо противного воет
- Автозапуск вместе с Windows и сворачивание в трей
- Проверка обновлений с GitHub Releases, без ручных скачиваний

## Как установить и настроить

Скачайте `VoiceBridge-Setup-1.0.0.exe` из раздела [Releases](https://github.com/zxchm0nya/VoiceBridge/releases), запустите, пройдите мастер (папка, ярлыки, кнопка «Установить»). В конце поставьте галочку «Запустить VoiceBridge».

Дальше по шагам:

1. В блоке «Маршрут» выберите свой наушники в поле «Система (вывод звука)».
2. В поле «Приёмник (микрофон)» выберите `CABLE Input (VB-Audio Virtual Cable)`.
3. Нажмите «Старт». Зелёный кружок и «Активно» внизу означают, что звук идёт.
4. В Discord: Настройки → Голос и видео → ввод → устройство ввода → `CABLE Output (VB-Audio Virtual Cable)`.
5. В Discord лучше выключить «Аппаратное усиление микрофона», иначе он может подавлять слишком громкий сигнал.

Про эхо: оно появляется, если Discord воспроизводит ваш голос в те же наушники, из которых идёт захват. Либо включите в Discord режим «Только при нажатии», либо поставьте отдельный выход для голосового чата. С разбором эхо помогает блок «Если слышите себя» в разделе «Помощь».

Если виртуального микрофона ещё нет, поставьте VB-Cable (в настройках программы это называется «Виртуальный кабель»), после чего перезайдите в «Маршрут» и выберите устройство заново.

## Сборка из исходников

```bash
git clone https://github.com/zxchm0nya/VoiceBridge.git
cd VoiceBridge

# Сборка приложения
dotnet build VoiceBridge.sln -c Release

# Или полный релиз (app + installer)
powershell -ExecutionPolicy Bypass -File build.ps1
```

После второго варианта готовый установщик лежит в `dist/VoiceBridge-Setup-1.0.0.exe`.

## Структура

- `VoiceBridge` — основное приложение (WPF, .NET 8, NAudio)
- `VoiceBridge.Installer` — установщик с проверкой и удалением
- `build.ps1` — чистка, сборка, упаковка setup
- `screenshots` — картинки для README
